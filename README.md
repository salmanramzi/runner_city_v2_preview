# Runner City V2 — graphics rebuild preview

نسخة تجريبية محسّنة لرسوم سباق الجري ثلاثية الأبعاد.

## موجود
- WebGL فعلي باستخدام ملفات محلية فقط.
- شارع مع واجهات مباني وعناصر إضاءة ومجسمات مستديرة.
- ثلاثة مسارات وعقبات وقفز وانزلاق وجمع عملات.
- تحكم باللمس وأزرار الجوال.
- نتيجة محلية في المتصفح وإطار استدعاء واجهات سناب.

## غير مكتمل
- هذه ليست شخصية Bitmoji 3D الرسمية.
- ملف snap-api.js مجرد placeholder وليس حزمة @snap/web-lens-api.
- لا يوجد دمج حقيقي لنموذج GLB أو التحريك الهيكلي.
- لم تختبر النسخة داخل سناب أو بمراجعة رسمية.
- لا ترفع هذا الملف إلى سناب على أنه إصدار إنتاجي.

## التشغيل
ارفع ملفات المجلد إلى GitHub Pages ثم افتح index.html على هاتفك.
النسخة تعالج الرسومات برمجيًا بالكامل ولا تستدعي محتوى خارجيًا.
